# Mission

Pass frontend interviews at the **4+ years (mid-senior)** level, with JavaScript and TypeScript as the first focus area.

## What "good" looks like
- Explain core JS (closures, `this`, prototypes, event loop, async) out loud, clearly, in under a minute each.
- Implement the classic utilities (debounce, memoize, Promise.all, LRU, EventEmitter…) from a blank file, with edge cases.
- Predict the output of tricky snippets without running them.
- In TypeScript: write generics, narrowing, discriminated unions, mapped/conditional types, and explain trade-offs.
- Talk about design decisions and trade-offs like a senior, not just recite definitions.

## Later (not yet)
React internals, browser performance, CSS/layout, system design for frontend, web security, testing strategy, behavioural stories.

## Constraints
Learner set the goal via the CLI; no interview date given yet – ask the teacher to set one to pace the plan.
